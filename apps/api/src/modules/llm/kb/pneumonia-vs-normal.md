پنومونی خفیف یا مراحل اولیه عفونت می‌تواند بسیار ظریف و کم‌واضح باشد. بررسی دقیق مناطق پشت قلب (رتوکاردیال)، نواحی ناف ریه (پری‌هیلار)، پشت تحدب دیافراگم و زوایای کوستوفرنیک ضروری است. چرخش بیمار، دم ناکافی و تکنیک تصویربرداری ضعیف ممکن است کدورت‌های کاذب شبیه به پنومونی ایجاد کنند.
